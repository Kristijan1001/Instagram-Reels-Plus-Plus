# Instagram Reels ++

A full-screen, keyboard-driven media viewer for Instagram on desktop.

Turns the feed, Explore and your bookmarks into a dark, distraction-free overlay: no sidebar,
no stories, no comments — just the post, with proper keyboard navigation.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/).
2. Open [`InstagramReelsPlusPlus.user.js`](InstagramReelsPlusPlus.user.js) and click **Raw** — your manager will offer to install it.
3. Open [instagram.com](https://www.instagram.com) and press **X**.

Or install from [Greasy Fork](https://greasyfork.org/en/scripts/551737-instagram-reels).

> Looking for the sidebar links, snap scrolling and floating navigation instead?
> That's the companion script, [Instagram Reels ++ Extension](https://github.com/Kristijan1001/Instagram-Reels-Plus-Plus-Extension).

## Features

- **Full-screen immersion** — sidebar, stories and comments hidden, content on a dark overlay.
- **Intelligent auto-scroll** — *Smart* mode waits for the video to finish and advances images
  after a short pause; *Timed* mode advances on a fixed delay (3s, 5s, 30s, …).
- **Skip-carousel mode** — jump straight to the next post instead of clicking through ten photos.
- **A real video player** — seeking and scrubbing, time display, volume, play/pause on hover.

## Controls

### Navigation
| | |
|---|---|
| **↑ / ↓** | Previous / next post (cycles carousel items first) |
| **← / →** | Cycle carousel media manually |

### Actions
| | |
|---|---|
| **L** | Like / unlike |
| **S** | Save / unsave |
| **F** | Follow / unfollow author |

### Playback
| | |
|---|---|
| **Space** | Play / pause |
| **,** or **<** | Back 5s |
| **.** or **>** | Forward 5s |
| **Double-click** | Mute / unmute |

### General
| | |
|---|---|
| **X** | Toggle Reels mode on / off |
| **Q** or **Esc** | Exit |

The mouse wheel navigates too — it handles carousels before moving on to the next post.
